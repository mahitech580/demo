# GitHub Demo

This repository is a simple demonstration of Git and GitHub.

## 🚀 What This Demo Shows

* Creating and managing a Git repository
* Tracking changes with Git
* Creating commits
* Pushing changes to GitHub
* Updating files through GitHub

## 🛠️ Technologies

* Git
* GitHub
* Markdown

## 📌 Purpose

This project is created for learning and demonstrating a basic GitHub workflow.

## 🔄 Git Workflow

```text
Create / Modify Files
        ↓
    git add
        ↓
   git commit
        ↓
    git push
        ↓
     GitHub
```
